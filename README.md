# MIGÕES VÔLEI

Plataforma de gerenciamento de atletas e competições de voleibol.

## Funcionalidades

- Consulta pública de atletas e ranking individual.
- Histórico e resultados de partidas.
- Módulo de torneios, equipes, jogos e classificação.
- Área administrativa com operações restritas a usuários MASTER e CHEFE.
- Integração com Supabase.

## Acesso e permissões

A consulta de informações é pública. Cadastros, alterações e exclusões são reservados aos usuários autorizados (MASTER/CHEFE), com validação também no banco de dados.

## Tecnologias

- HTML, CSS e JavaScript
- Supabase
